# Mode: defense style

Use for Chinese oral defense scripts, project presentations, competition reports, slide narration, and speech drafts.

Source family: B group — CUIE oral notes, MESA midterm/final notes, iCan defense draft, charging-station problem oral/overview materials. A group excluded.

## Core voice

- Audience-facing, oral, and technical.
- Uses first person plural: `我们`, `我们的工作`, `我们希望`.
- Opens politely, then gives roadmap.
- Explains motivation before formulas or model details.
- Sentences are shorter than manuscript prose. One sentence should be speakable in one breath.
- Technical terms are allowed, but each dense idea needs a spoken bridge.

## Speech architecture

1. **Greeting and topic**
   - `各位老师、同学，大家好。`
   - `今天向大家汇报的工作是...。`
   - `很荣幸能代表项目组...。`

2. **Roadmap**
   - `我将从...几个方面展开。`
   - Use 4-6 parts at most. Avoid long lists.

3. **Motivation**
   - Start from real-world pressure or technical contradiction.
   - Common pattern: `一方面...；另一方面...。`
   - End with question or need: `那么，对于这样的...，如何...？`

4. **Method explanation**
   - Move from intuition to equation/model.
   - Use `具体来说`, `这里`, `可以看到`, `对应到我们的模型中`.
   - When formulas appear, explain what each variable means and why it is introduced.

5. **Experiment/result**
   - State what was compared and what was observed.
   - Tie result back to the earlier motivation.

6. **Summary and closing**
   - `最后，对我们的工作做一个总结。`
   - Thank audience: `以上就是我的汇报，请各位老师批评指正。`

## Sentence habits

- Use oral transitions: `首先`, `接下来`, `然后`, `最后`, `这里`, `可以看到`, `也就是说`.
- Use rhetorical questions only to introduce a problem, not every section.
- Keep formulas surrounded by explanation.
- Prefer `这个问题`, `这类数据`, `我们的模型` over abstract nouns stacked together.
- Repeat key terms intentionally so listeners do not lose the thread.

## Preferred phrasing

- `各位老师、同学，大家好。今天向大家汇报...`
- `我将从动机、方法、实验和总结几个方面展开。`
- `随着...的发展，...不断涌现。`
- `这就带来了一个问题：...。`
- `具体来说，我们首先...，然后...。`
- `从实验结果可以看到，...。`
- `以上就是我的汇报，请各位老师批评指正。`

## Avoid

- Manuscript-only phrasing that sounds unreadable aloud.
- Overlong nested sentences with multiple subordinate clauses.
- Dense citation-style related work unless the defense requires it.
- Generic AI speech polish: `今天我非常激动地站在这里`, `开启一段探索之旅`, `具有深远意义`.
- Excessive humility or flattery.

## Rewrite calibration

When converting written prose into defense style:

- Add roadmap and signposts.
- Move background before definitions.
- Replace dense nominal phrases with explainable verbs.
- Split long sentences.
- Add slide cues only when the user is writing slide narration.
