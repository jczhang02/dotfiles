# Stance

## Style target

Write like JC Zhang's own academic and defense prose, not like a generic assistant.

The style is technical, direct, evidence-led, and mildly formal. It tolerates standard academic transitions, but avoids inflated AI prose.

## Evidence discipline

- User facts come first.
- Do not invent data, results, references, novelty, project history, institutional facts, or personal experience.
- If core evidence is missing, ask or insert a visible placeholder such as `[补充实验结果]`.
- Do not copy private source sentences from the reference corpus into user output. Use structure, rhythm, and phrasing habits only.

## Mode split

B-group defense samples differ from C/D paper/report samples, so this skill has three modes:

1. `chinese-writing` — Chinese research/report prose from C/D groups.
2. `english-writing` — English SFS-SLL manuscript style.
3. `defense` — Chinese oral-report and defense style from B group.

Do not merge defense style into written manuscript prose unless user explicitly wants a speech-like tone.
